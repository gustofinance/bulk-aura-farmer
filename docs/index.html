Useful because it is inspectable.

The bot keeps the moving parts visible: public market data, local signing, a single account, explicit fee assumptions, and a bounded position lifecycle. Fork it when you want a starting point for a market-data tool, volume experiment, or maker strategy.

01 / BookRead the selected market's top bid.
02 / MakerPlace ALO at the bid and wait.
03 / TakerCross only for unfilled size.
04 / ProtectSet range/OCO exit thresholds.
05 / FlattenClose on exit or max hold.

Start on testnet.

Use a dedicated trading account. The default configuration does not submit orders. Once you understand the account, market rules, fees, and collateral requirements, you can enable live testnet execution with a small size.

1. Create access

Open BULK through our disclosed referral, complete the current onboarding requirements, and fund a dedicated account only as appropriate for your test.

2. Run the POC

Clone the repo, copy .env.example, set your private key locally, keep NETWORK=testnet, and begin with DRY_RUN=true.

3. Measure reality

Compare fills, fees, funding, slippage, realized PnL, position time, and the current AURA rules. Never infer reward eligibility from volume alone.

AURA, volume, and open interest.

BULK's current program uses trading-earned Ranked Aura to place traders on the seasonal Challenger Series ladder. Ranks can move weekly through promotion and demotion; pre-deposit and BulkSOL Aura is unaffected but does not count toward rank. This project cannot read, claim, or guarantee AURA.

Referral disclosure: the YETI links on this page are referral links for this project. No AURA, airdrop, return, or eligibility outcome is guaranteed.

Executed volume

Only filled orders create executed notional. Resting orders and rejected ALO orders are not the same as Ranked Aura activity.

Open interest

A position can affect open interest while it is open. The bot exits or refuses a new round when the selected account is not flat.

Costs and rank

Fees, funding, spread, impact, liquidation risk, and weekly rank movement all matter. Re-check BULK's live rules.

Developer FAQ

Is this an official BULK bot?

No. It is an independent open-source TypeScript example using BULK's public APIs and signing library.

Does it guarantee AURA or an airdrop?

No. The official BULK app and documentation control current program rules. Treat all reward outcomes as unknown until confirmed by BULK.

Can I use mainnet?

The code supports mainnet, but testnet and dry-run are the defaults. Mainnet requires an explicit confirmation environment variable and a dedicated account.

Where do I extend it?

Start with WebSocket account streams, exchange-info precision checks, PnL/fill accounting, circuit breakers, short mode, and inventory-aware quoting.
